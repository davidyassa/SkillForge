### Steps to use Library Folder
1. [Download it](https://drive.google.com/drive/folders/1Gb7Bkg0qVacCZxj5g7fgCnrdt4cJSaj-?usp=drive_link)
2. On Netbeans, go to `Project > RightClick > Properties>Libraries`
3. Click on the `+` next to "Classpath" `> add JAR/Folder`
4. Select all JAR files in the folder you've just downloaded

Note: (each time you clone the repo you'll need to repeat steps 2-4)
